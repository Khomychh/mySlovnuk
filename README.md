# Словник

PWA для власного списку слів: переклад, транскрипція, коментар, інтервальне повторення (SM-2, як в Anki), автоозвучення через голоси браузера, резервна копія в Google Диску.

Без збірки й залежностей: звичайні статичні файли.

## Запуск локально

```sh
python -m http.server 5173
```

Відкрийте http://localhost:5173. Service worker і встановлення як застосунку працюють лише на `localhost` або через HTTPS.

## Публікація

Підійде будь-який статичний хостинг з HTTPS: GitHub Pages, Netlify, Cloudflare Pages. Після оновлення файлів змініть `VERSION` у `sw.js`, щоб телефони отримали нову версію.

## Резервна копія в Google

Застосунок пише один файл `slovnyk-backup.json` у приховану папку застосунку на вашому Диску (`appDataFolder`, доступ `drive.appdata`). Інших файлів на Диску він не бачить.

Потрібен власний OAuth Client ID (один раз):

1. https://console.cloud.google.com/ → створіть проєкт.
2. **APIs & Services → Library** → увімкніть **Google Drive API**.
3. **OAuth consent screen**: тип External, додайте себе в **Test users**.
4. **Credentials → Create credentials → OAuth client ID** → тип **Web application**.
5. У **Authorized JavaScript origins** додайте адреси, з яких відкриваєте застосунок, наприклад `http://localhost:5173` і `https://ваш-домен`.
6. Скопіюйте Client ID у `config.js` (`googleClientId`). Користувачі його не бачать і нічого не налаштовують: вони просто натискають «Увійти через Google». Поки ID не вказано, кнопка неактивна, а значок синхронізації вгорі прихований.

### Відкрити вхід для всіх

Поки проєкт у режимі **Testing**, увійти можуть лише Test users (до 100). Щоб відкрити для всіх: OAuth consent screen → **Publish app**. Google попросить назву, email підтримки й посилання на політику конфіденційності: це `https://ваш-домен/privacy.html`. Перед публікацією замініть у `privacy.html` обидва `CONTACT_EMAIL` на свою адресу.

Синхронізація об'єднує записи: для кожного слова перемагає новіша зміна, тож можна користуватися словником на кількох пристроях. Після кожної зміни копія оновлюється сама (через 3 с), поки дійсний вхід у Google (близько години; потім застосунок попросить увійти знову).

## Кілька мов

Кожна мова — окремий список: свої слова, своя черга повторень, ціль дня, голос і швидкість. Мову перемикають у Параметрах → «Мова, яку вивчаю». Там же додають нову мову, а порожню можна прибрати. Резервна копія в Google одна на всі мови.

Слова з файлу без поля `lang` додаються до поточної мови.

## Підказки транскрипції

- **Транскрипція** (лише англійська): [dictionaryapi.dev](https://dictionaryapi.dev). Показуються всі знайдені варіанти з позначками брит./амер. Першою стоїть вимова, що відповідає вибраному голосу. Для омографів (lead, tear, record) варіанти згруповані за значенням з коротким англійським визначенням.
- Різні значення з різною вимовою краще тримати окремими картками. Якщо слово вже є, застосунок покаже його переклад і транскрипцію й запропонує зберегти другу картку.

## Форми й неправильні дієслова

Поле «Форми» в редакторі: інші форми слова через кому, без самого слова. Для неправильних дієслів `went, gone`, для множини `children`, для ступенів порівняння `better, best`.

На картці до відкриття перекладу видно нагадування «Згадайте переклад і 2 форми». Після відкриття форми показані рядком `go` `went` `gone`, кожну можна торкнутися, щоб почути. Автоозвучення читає «go, went, gone», а потім приклади.


## Приклади

У редакторі поле «Приклади»: кожен приклад з нового рядка, переклад після `|` (необов'язково):

```
I love you | Я люблю тебе
Love is all you need
```

На картці приклади з'являються після відкриття перекладу, кожен зі своєю кнопкою прослуховування. Якщо в Параметрах увімкнено «Читати приклади, коли відкривається переклад» (окремо для кожної мови), вони звучать по черзі автоматично. Клавіша E читає форми й приклади ще раз. У реченні голос правильно вимовляє омографи (lead у «made of lead»), тож приклад — найкращий спосіб почути саме ваше значення.

## Ціль дня і прогрес

Вкладка «Прогрес» окрема для кожної мови. Ціль — скільки різних слів повторити за день (за замовчуванням 10, задається на цій вкладці).

- Слово рахується один раз на день, навіть якщо через «Знову» воно випало кілька разів.
- Додане слово одразу рахується як повторене: +1 до цілі дня. У черзі повторень воно з'явиться завтра.
- День: «ціль досягнуто», «спроба» (повторено менше за ціль) або «без повторень». Минулі дні зберігають ціль, яка діяла тоді.
- Лічильники за тиждень, місяць, рік і весь час рахують дні від першого дня навчання цієї мови. Натисніть на лічильник, щоб побачити діаграму, а на день у календарі, щоб побачити його статистику.

## Клавіші під час повторення

- Пробіл / Enter: показати переклад
- 1–4: Знову / Важко / Добре / Легко
- R: повторити вимову

## Файли

- `index.html`, `styles.css`, `app.js`: застосунок
- `config.js`: Google Client ID
- `sw.js`: офлайн-кеш
- `manifest.webmanifest`, `icons/`: встановлення як PWA
